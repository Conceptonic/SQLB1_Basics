Практический курс по основам SQL на реляционной базе данных PostgreSQL. В качестве предметной области используется система пиццерий с таблицами клиентов, меню, посещений и заказов. Все задания выполняются в виде отдельных SQL-скриптов.

Технологии и инструменты:

PostgreSQL
ANSI SQL
DataGrip / pgAdmin / psql
Git (GitLab, ветка develop)

Чему научился:

Написание SELECT-запросов с фильтрацией (WHERE, BETWEEN, операторы сравнения)
Фильтрация по диапазону дат
Сортировка по нескольким полям с разными направлениями (ASC/DESC)
Конкатенация и форматирование строк в вычисляемых полях
Условная логика в запросах (CASE WHEN)
Внутренние подзапросы в части SELECT и FROM
Фильтрация чётных/нечётных записей через остаток от деления
Работа с реляционной схемой из нескольких связанных таблиц (первичные и внешние ключи)
Применение ограничений на синтаксис (решение задач без JOIN и без IN)
